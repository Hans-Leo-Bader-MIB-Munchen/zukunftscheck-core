# zukunftscheck-core

Private technical core for the ZukunftsCheck project.

Current development scope: **ZS-KI-B deterministic schema/reference validation** based on the fachlich approved ZS-KI-B architecture v0.1.1.

## Binding constraints

- local-first and provider-neutral
- deterministic validation before AI
- no autonomous fachliche, legal, technical, economic, governance, stage or release decisions
- no real data in the current development block
- no LLM / LM Studio integration in the current development block
- ZS-KI-A v1.10 remains FROZEN and closed
- Stage 1 reference remains PF1–PF12 / 67 questions; no parallel method/status system

Canonical governance and documentation remain in the controlled ZukunftsCheck Google Drive structure. This repository is the controlled code location, not a new source of fachliche truth.
